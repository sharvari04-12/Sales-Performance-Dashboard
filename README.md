# Sales Performance Dashboard (Power BI)

## Project Overview
This project presents an interactive Sales Performance Dashboard developed using Microsoft Power BI to analyze sales, profit, customer trends, 
regional performance, and product categories.
The dashboard helps business users monitor KPIs, identify high-performing products, and make data-driven decisions.

---

## Dashboard Features
- Sales, Cost and Profit KPIs
- Customer-wise Sales Analysis
- Product Category Performance
- Regional Sales Distribution
- Order Trend Analysis
- Interactive Filters
- Date Range Slicer
- Ship Mode Analysis

---

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Excel Dataset

---

## Key Insights
- Total Sales: **173.8K**
- Total Cost: **88.6K**
- Total Profit: **85.3K**
